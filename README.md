# 🏢 IT Asset Management & Telegram Bot (Google Sheets Sync)

Комплексная система учета и оприходования IT-оборудования компании с двусторонней синхронизацией с Google Таблицами («Лист1 (копия)» и «Склад»), автоматической загрузкой сканов/фото накладных в Google Диск и круглосуточным Telegram-ботом.

---

## 🚀 Основные возможности

1. **📋 Лист1: Оборудование сотрудников**
   - Учет закрепленной техники: ФИО, Должность, Отдел, Филиал, Ноутбук/ПК, Монитор, Периферия, Серийные номера, Даты выдачи.
   - Проверка и аудит дубликатов серийных номеров и инвентарных ID.
   - Редактирование, удаление, добавление новых сотрудников прямо из интерфейса.

2. **🏢 Лист «Склад»: Оприходование и выдача**
   - 8-колоночный учет прихода техники по накладным.
   - Оприходование с прикреплением фото/скана документа — файл мгновенно загружается в Google Диск в папку накладных, а ссылка заносится в таблицу.
   - Выдача техники со склада сотруднику в 1 клик со списанием остатков и записью на «Лист1».

3. **🤖 Круглосуточный Telegram-бот (24/7)**
   - Поиск сотрудника и закрепленного оборудования по фамилии или имени (`/find Иванов`).
   - Поиск оборудования по серийному номеру или инвентарному ID (`/check C02X1234`).
   - Добавление нового сотрудника и выдача техники через диалог в Telegram (`/add_employee`).
   - Оприходование новой партии прямо из Telegram с отправкой фото накладной (`/receipt`).
   - Справка по остаткам на складе (`/warehouse`).
   - Экспорт резервной копии данных (`/backup`).

4. **⚡ Мгновенная синхронизация через Google Apps Script Webhook**
   - Двусторонняя синхронизация в реальном времени.
   - Любое изменение в приложении или боте сразу отображается в Google Таблице.

5. **📊 Аналитика и профилирование**
   - Профиль колонок, процент заполненности, числовые агрегации.
   - Визуализация на графиках (Recharts).
   - Сводные таблицы и группировка по отделам/филиалам.

---

## 🛠 Технологический стек

- **Frontend**: React 19, TypeScript, Tailwind CSS, Vite, Lucide Icons, Recharts
- **Backend**: Node.js, Express, tsx
- **Интеграции**: Telegram Bot API, Google Sheets Webhook (Google Apps Script), Google Drive API

## 📦 Быстрый старт

### 1. Клонирование и установка зависимостей
```bash
git clone https://github.com/ZOgithubHA/fp_sheets.git
cd fp_sheets
npm install
```

### 2. Настройка конфигурации
Создайте файл `server/sync-config.json` (или воспользуйтесь веб-интерфейсом):
```json
{
  "spreadsheetUrl": "https://docs.google.com/spreadsheets/d/17mxs3jdsSjeQQtDWmxUuQ72s7F9QmJMU12Am0uKPs6Q/edit?usp=sharing",
  "telegramToken": "8661379316:AAGtH3hBc964NlBMVFNnfiDYT5qpzO2BlJI",
  "googleAppsScriptUrl": "https://script.google.com/macros/s/AKfycbx9hHaDF_k1dy5TJt4yCLRFlcAQIXFn3yzP70T8r9yW6cqtP9QZlEJ-BLhNxOnCAHrG/exec"
}
```

### 3. Запуск веб-приложения и сервера
```bash
npm run dev
```
Приложение откроется на `http://localhost:3000`.

### 4. Запуск Telegram-бота (автономно)
```bash
npm run bot
```
